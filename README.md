# Mesa del Máster

Juego de rol de mesa con reglas 5e (SRD 5.2) y un máster IA. Campaña sin final para hasta 10 personajes: empiezas como plebeyo con 17 años y puedes llegar a rey, formar una familia, gobernar tierras, intrigar y dejar un legado.

**Jugar:** https://juancarlos15022-maker.github.io/mesa-del-master/

## Cómo empezar
1. Abre el enlace y crea una cuenta con tu correo.
2. En **Ajustes**, pega tu clave de la API de Anthropic (se consigue en console.anthropic.com; cada turno del máster se cobra en tu cuenta).
3. Crea una campaña o únete a una, crea tu personaje y pulsa «Comenzar la aventura».

## Instalarla como app
- **Android (Chrome):** botón «Instalar app» o menú ⋮ → Instalar aplicación.
- **iPhone (Safari):** Compartir → Añadir a pantalla de inicio.
- **PC (Chrome/Edge):** icono de instalar en la barra de direcciones.

Las partidas se guardan en una base de datos común (Supabase) y son compartidas por todos los jugadores registrados.
