# Mesa del Máster

Rol de mesa con reglas 5e y un máster IA. Se juega gratis dentro de Claude, con la cuenta de cada jugador.

**Página de bienvenida:** https://juancarlos15022-maker.github.io/mesa-del-master/

1. Descarga Claude (gratis): https://claude.ai/download
2. Pide acceso al anfitrión (mándale el correo de tu cuenta de Claude).
3. Abre el juego: https://claude.ai/artifact/4xpeGk8vWJ9nVB7UcLo7YT

La carpeta `version-supabase/` guarda una versión independiente (base de datos propia y clave de API) por si en el futuro se quiere usar.
